Dougal's map

Two things were mined off The Park Map, Fourth Edition: names printed on it that match no property in the record, and the architect each house's fill colour points to. Neither is evidence. This page puts each one beside what the record already holds, so it can be judged rather than imported.

Nothing here changes the record. Keeping a row marks it worth acting on; passing it says it is not, and neither is offered again.
